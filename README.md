# McMap

Every McDonald's on Earth, on one map. Red pins are ones you haven't been to,
green pins are ones you have.
Tap a pin to rate that McDonald's out of five,
mark as visited and get directions on Apple and Google Maps.

Not all McDonald's restaurants are included. You can view where the data is from below.

** [rquw.github.io/McMap](https://rquw.github.io/McMap)**

Restaurant data: [OpenStreetMap](https://www.openstreetmap.org) via [QLever](https://qlever.dev)
Basemap: [OpenFreeMap](https://openfreemap.org)
Boundary outlines and place search: [Nominatim](https://nominatim.openstreetmap.org)

Not affiliated with McDonald's in any way. This is a personal side-project.
